# Продуктовые правила MVP

GooseSwitcher в рамках MVP работает как IBus-движок для Fedora Linux и
поддерживает только русскую и английскую раскладки. Глобальный перехват
клавиатуры не используется.

## Исправление слов

- Проверка и возможное исправление запускаются при завершении слова пробелом,
  знаком пунктуации или клавишей Enter.
- Контекстная оценка и частотная языковая модель не используются.
- Автозамена выполняется только при высокой уверенности: преобразованный вариант
  присутствует в словаре, а исходный — отсутствует.
- URL, адреса e-mail, пути, числа и кодоподобные токены не исправляются.

## Управление

MVP должен предусматривать горячие клавиши для:

- исправления последнего слова;
- отмены последнего исправления;
- временного отключения исправлений.

## Пользовательский словарь

Пользовательские правила имеют приоритет над системными словарями и поддерживают
три действия:

- «считать корректным»;
- «никогда не исправлять»;
- «всегда заменять» с указанием варианта замены.

## Хранилище

Настройки и пользовательские словарные правила хранятся в SQLite со схемой
версии 1. База располагается в
`$XDG_DATA_HOME/gooseswitcher/gooseswitcher.db`. Если `XDG_DATA_HOME` не задан,
используется `$HOME/.local/share/gooseswitcher/gooseswitcher.db`.

Схема содержит таблицы `settings` и `user_rules`. Версия схемы хранится в
`PRAGMA user_version`; база с версией новее поддерживаемой не открывается.
